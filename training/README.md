# 연수 신청 화면 주소 변경

현재 신청 화면과 관리자 화면은 [pace33/training](https://github.com/pace33/training) 저장소의 루트에서 관리합니다.

- 신청: https://pace33.github.io/training/
- 관리자: https://pace33.github.io/training/manage.html

이 폴더의 기존 주소는 새 주소로 자동 이동합니다. 데이터 API와 서버 소스는 기존대로 유지하므로 신청 데이터·PIN·선정 내역·관리자 설정은 주소 변경으로 초기화하지 않습니다. 화면 수정은 pace33/training 저장소에 반영하세요.
